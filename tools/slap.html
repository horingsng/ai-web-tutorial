👊 教訓老細

上載張相做老細塊面・辦公室 6 樣道具任你教訓佢

🖼️ 撳呢度上載老細張相
（前度、星期一、邊個都得，你話事）

拖郁張相、兩指縮放（或撳 ＋−），將佢個頭對入頭型框：

🤵 老細血量
哎吔！
😵‍💫
🖥️顯示器
🪑摺凳
🖨️影印機
☕熱咖啡
🚰水機
🪴盆栽
撳任何一樣道具教訓佢！
🔒 張相只喺你部機處理，唔會上傳去任何地方，放心玩。

📥 鍾意？拎走佢！

呢個遊戲係一個獨立 HTML 檔。撳下面個制下載落部機——雙擊即用，離線都玩得，send 俾同事一齊教訓老細都得。

🛠️ 想改？咁樣同 AI 講（連方法都教埋你）

下載個檔，上載去 ChatGPT / Claude / Kimi，跟住抄。留意每句都講埋用咩技術做——你唔使識，但 AI 見到關鍵字就會行啲路：

  • 加新道具：「參考現有道具嘅做法，每樣道具係一行 HTML，用 data-dmg 控制威力、data-yell 控制對白、data-rate 控制聲效音調。幫我加：電話、鍵盤、文件櫃。」
  • 加/改音效：「而家嘅聲效係用 Web Audio API 即場生成（冇外置音效檔，先可以單檔離線玩）。幫我加多幾種：重擊用低頻 noise＋慢衰減，摑擊用高頻短促，水機加個水花聲。全部要 Web Audio 生成，唔好叫我另外下載檔案。」
  • 老細變樣（而家已經係咁做）：「而家係用 CSS filter（saturate/brightness/hue-rotate）加半透明 radial-gradient 瘀痕疊層，跟血量逐漸加深。幫我加：眼鏡碎裂（半血先出現）、甩頭髮、最後變豬頭。」
  • 加對白：「老細對白分兩層：道具專屬（data-yell）同求饒池（begs 陣列隨機抽）。幫我將求饒池加到 30 句，語氣越嚟越衰，最後十句要講到喊。」
