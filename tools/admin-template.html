🗂️ 公司後台管理模板

總覽・訂單・存貨・出糧・員工登入（接駁 Firebase 後多人即時同步）

🧪 示範模式：而家資料只存喺你部機，可以即刻試玩。貼上你自己嘅 Firebase 密鑰，就會自動變成多人同步嘅正式版（睇教學點攞密鑰，10 分鐘搞掂）。
🗂️ 開心果集團 後台

📥 拎走佢，變成你公司個系統

撳下面個制下載個 HTML 檔。跟住Firebase 教學攞你公司嘅密鑰，貼入檔案頂部 firebaseConfig 位置，放上网——就係你公司嘅正式後台。

🛠️ 想改？咁樣同 AI 講（連方法都教埋你）

下載個檔，上載去 ChatGPT / Claude / Kimi，跟住抄。每句都講埋用咩技術做：

  • 換用途：「呢個後台用三個 Firestore collection：orders／inventory／payroll。幫我將『存貨』改成『預約管理』：欄位變 客人／服務／日期時間／狀態，collection 改名 bookings，總覽嗰張低存貨卡改成今日預約數。」
  • 加搜尋同分頁：「幫訂單列表加搜尋框：資料少就直接前端 filter 客戶名。加個簡單分頁（每頁 20 條），唔好用外部分頁插件。」
  • 加權限分級：「加個 role 欄位：Firestore 每個 user 文檔記住 admin 定 staff，admin 先見到刪除制同出糧頁。Firestore Rules 都要跟住改，寫明俾我貼。」
  • 加圖表：「總覽頁加個最近 30 日營業額走勢：用純 canvas 畫條折線圖，唔好用外部圖表庫，資料由 orders collection 按日加總。」
