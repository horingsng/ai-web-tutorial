🏪 產品介紹頁模板

小商店一頁式開賣：產品卡＋價錢＋WhatsApp 落單制

👆 上面係示範店，下載之後改兩行就係你間店

📥 拎走佢，變成你間店

撳下面個制下載個 HTML 檔。店名、產品、價錢全部寫喺檔案最頂嘅一個資料陣列入面，用記事本改都得；WhatsApp 號碼都係改一個數字。

🛠️ 想改？咁樣同 AI 講（連方法都教埋你）

下載個檔，上載去 ChatGPT / Claude / Kimi，跟住抄。每句都講埋用咩技術做：

  • 換你嘅產品：「產品資料係檔案頂部一個 JavaScript 陣列（PRODUCTS），每項有 emoji／名／價錢／簡介。幫我換成：……（貼你嘅產品清單）」
  • 加產品相：「而家產品用 emoji 做圖。幫我加個 image 欄位支援本地相：如果 image 有值就顯示相，冇就用 emoji，相用 base64 內嵌保持單檔。」
  • 改落單方式：「而家撳制係開 wa.me 帶預設訊息。幫我加多個選擇：可以揀 WhatsApp 或者複製訂單文字，電話號碼同訊息格式放喺頂部 SHOP 設定度。」
  • 放上网：整完跟免費發佈教學放上网，你間店就有條正式 link 可以印落卡片度。
