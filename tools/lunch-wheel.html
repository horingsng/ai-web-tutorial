🎡 午餐輪盤

「今日食咩」一轉定局・唔准反口

🔻
㩒「開轉」睇今日食咩

🍽️ 選項（會自動記住）

成個辦公室圍住部電話，一人轉一次，轉到乜食乜，唔准反口😤

📥 鍾意？拎走佢！

呢個工具係一個獨立 HTML 檔。撳下面個制下載落部機——雙擊即用，離線都玩得，send 俾同事一齊轉都得。

🛠️ 想改？咁樣同 AI 講（連方法都教埋你）

下載個檔，上載去 ChatGPT / Claude / Kimi，跟住抄。每句都講埋用咩技術做，AI 見到關鍵字就會行啲路：

  • 換用途：「呢個輪盤係用 canvas 畫扇形，選項存喺 JavaScript 陣列。幫我改成『邊個請食飯』輪盤，預設選項做人名，標題同用字都跟住改。」
  • 加權重：「幫每個選項加個『權重』數字，轉嗰陣唔係平均機會，係按權重加權抽籤（weighted random），畫扇形嗰陣扇形大細都跟權重變。」
  • 加聲效：「轉嗰陣用 Web Audio API 加滴答聲（越轉越慢滴答越疏），停嗰刻加個叮一聲。全部即場生成，唔好用外置音效檔。」
