減肥第一步，唔係節食，係「知數」

好多人減肥淨係「食少啲」，但少幾多先啱？食得太少身體會慳能源，越減越難瘦。科學做法係先計三個數：BMI（你而家嘅體重狀況）、TDEE（你一日實際燒幾多卡路里）、每日卡路里上限（想減就要食得少過 TDEE 大概 300-500 kcal）。

網上嘅 BMI 計算機十居其九係廣告農場 —— 計條數要先睇三個廣告，仲要碌到頁尾先見到個掣。自己整一個：輸入身高體重年齡，三個數一撳出齊，五秒搞掂。

成品功能預覽

  • ⚖️ BMI 計算 + 標準範圍對照（過輕/正常/過重/肥胖分級）
  • 🔥 TDEE 計算：跟性別、年齡、身高、體重、活動量計每日總消耗
  • 🎯 減脂/維持/增肌三個目標嘅每日卡路里建議
  • 📏 顯示你身高對應嘅「健康體重範圍」
  • 📱 手機用得，離線計到，數據唔出你部機

第一步：複製 Prompt 俾 AI

開啟 ChatGPT、Claude 或 Kimi，成段複製貼上：

【角色】你係資深前端工程師，同時熟悉健身營養學嘅計算公式。 【任務】生成一個「BMI 健康計算機」網站，單一 HTML 檔案，可直接開啟使用。 【目標用戶】想減肥或健身嘅香港人，唔想下載 App 【功能規格】 - 輸入欄位：性別（男/女切換掣）、年齡、身高（cm）、體重（kg）、活動量（5 級選擇：久坐/輕量/中度/高度/運動員） - 撳「計算」後一次過顯示： 1. BMI 數值（小數點後一位）+ 所屬級別（過輕 <18.5 / 正常 18.5-22.9 / 過重 23-24.9 / 肥胖 ≥25，用亞洲標準） 2. BMI 級別用顏色顯示：正常綠色、過輕同過重黃色、肥胖紅色 3. 健康體重範圍（按身高用 BMI 18.5-22.9 反推） 4. BMR 基礎代謝率（用 Mifflin-St Jeor 公式） 5. TDEE（BMR × 活動量系數：1.2 / 1.375 / 1.55 / 1.725 / 1.9） 6. 三個目標嘅每日卡路里：減脂（TDEE - 400）、維持（TDEE）、增肌（TDEE + 300） - 結果區域用大卡片顯示，數字要超大 - 每個數字下面有一句中文解釋（例如「呢個係你瞓喺度一日都會燒嘅卡路里」） - 用 localStorage 記住上次輸入嘅數據 【設計要求】 - 簡潔專業風格，健康感配色（白底 + 綠色主調） - 手機優先設計（響應式） - 按鈕要夠大，數字要夠搶眼 【技術限制】 - 單一 HTML 檔案，內嵌 CSS + JavaScript - 唔使用外部圖片或框架 - 完全離線可用 - 程式碼要有中文註釋 - 頁面底部加一句免責聲明：「以上數據僅供參考，如有健康問題請諮詢醫生」 【輸出】 請輸出完整 HTML code，我會直接儲存為 .html 檔案使用。

第二步：儲存做 HTML 檔案

1

複製 AI 輸出嘅完整代碼

由 <!DOCTYPE html> 到最後 </html>，一行都唔好漏。

2

記事本貼上，另存新檔

檔名 bmi.html，儲存類型揀「所有檔案」，編碼 UTF-8。

3

雙擊開啟，計吓自己嘅數

輸入你嘅資料撳計算 —— BMI、TDEE、三個目標卡路里應該一次過出齊。可以用網上任何 BMI 計算機對一對 BMI 嗰個數驗證吓。

第三步：點用呢三個數

  • 想減脂：每日食「減脂」嗰個數，唔好再低 —— 低過 BMR 身體會抗議
  • 想增肌：食「增肌」嗰個數 + 夠蛋白質 + 重量訓練
  • BMI 過重：目標係行入「健康體重範圍」，唔使一步到位的
想追蹤進度？同 AI 講「加個體重記錄功能，每次磅重入數，畫條走勢線」—— 就變成你嘅私人減重日記，配合 儲蓄追蹤器教學 嘅進度條概念一樣。

按需要微調（直接同 AI 講）

  • 「加個體脂率估算（用美國海軍公式，要輸入頸圍腰圍）」
  • 「加個每日蛋白質建議（體重 × 1.6-2.2g）」
  • 「加個飲水量建議（體重 × 33ml）」
  • 「加個目標日期倒數，預計幾時到健康體重」

常見問題 FAQ

Q：BMI 點解用亞洲標準唔用世衛標準？

A：研究發現亞洲人喺較低 BMI 已經有較高嘅健康風險，所以亞洲標準係 23 以上算過重（世衛係 25）。我哋個 Prompt 已經寫明用亞洲標準，啱香港人用。

Q：肌肉多嘅人 BMI 咪好唔準？

A：啱，BMI 分唔到肌肉同脂肪，健身人士會被誤判「過重」。所以個工具仲有 TDEE 同其他指標互補 —— 想更準，叫 AI 加體脂率估算功能。

Q：我嘅身高體重資料會上傳去邊？

A：邊度都唔會去。所有計算喺你部機做，資料只存你嘅瀏覽器。相比啲健康 App 要你開帳號交數據，呢個係最私隱嘅做法。

總結

知道自己嘅數字，先至談得上管理身體。五秒計好三個關鍵數，唔使睇廣告、唔使開帳號、唔使俾人收咗你嘅健康數據。整完不妨睇埋 To-do List 教學，將你嘅健身計劃變成每日行動清單。
