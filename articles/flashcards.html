點解要自己整生字卡？

每個香港家長都經歷過：聽日默書，今晚同小朋友抽問生字。傳統做法係自己寫字卡、或者買現成嘅 —— 但現成字卡永遠唔會啱你個小朋友今個星期嘅默書範圍。

自己用 AI 整一個：將老師派嘅生字表打落去，即刻變成一個有獎勵、有記錄嘅認字遊戲。中文默書、英文 Spelling 都用得，下星期換批生字，改幾隻字就得。

成品功能預覽

  • 🃏 生字卡模式：撳一下翻面，睇字睇解釋/讀音
  • 🎲 隨機抽問：唔會次次同一順序，小朋友冇得靠背位置
  • ⭐ 答啱有星星，儲夠星星有鼓勵畫面
  • 📊 記低邊啲字答錯過，最後出個「要重溫」清單
  • ✏️ 家長可以自己改字庫，今個星期默咩就入咩

第一步：複製 Prompt 俾 AI

開啟 ChatGPT、Claude 或 Kimi，成段複製貼上：

【角色】你係資深前端工程師，同時係兒童學習遊戲設計專家。 【任務】生成一個「生字卡認字練習」網站，單一 HTML 檔案，可直接開啟使用。 【目標用戶】5-9 歲香港小朋友（由家長協助設定字庫） 【功能規格】 - 兩個模式：「學習模式」（逐張卡睇，撳卡翻面顯示答案）同「測驗模式」（隨機抽問） - 字卡內容：正面顯示題目（例如英文單字 apple），背面顯示答案（中文意思 + 例句） - 測驗模式：顯示題目，小朋友口頭答，家長撳「答啱」或「答錯」掣 - 答啱加一粒星星，畫面頂部顯示星星總數 - 答錯嘅字會記低，測驗完結後顯示「需要重溫」清單 - 內置 10 張示範字卡（英文生字配中文意思） - 有「編輯字庫」區域：一個大文字框，每行一張卡，格式係「題目|答案」，儲存後即刻生效 - 用 localStorage 儲存字庫同星星紀錄 【設計要求】 - 鮮豔活潑風格，適合小朋友 - 字卡要超大，字體至少 40px - 撳掣要夠大，細路手指都撳得中 - 翻面有簡單動畫效果 - 手機優先設計（響應式） 【技術限制】 - 單一 HTML 檔案，內嵌 CSS + JavaScript - 唔使用外部圖片或框架，用 Emoji 做裝飾 - 支援離線使用 - 程式碼要有中文註釋 【輸出】 請輸出完整 HTML code，我會直接儲存為 .html 檔案使用。

第二步：儲存做 HTML 檔案

1

複製 AI 輸出嘅完整代碼

由 <!DOCTYPE html> 到最後 </html>，一行都唔好漏。

2

記事本貼上，另存新檔

檔名 flashcards.html，儲存類型揀「所有檔案」，編碼 UTF-8。

3

雙擊開啟，試玩示範字卡

應該見到字卡、兩個模式切換、星星計數。試撳翻面同「答啱/答錯」。

第三步：入返自己嘅默書範圍

撳「編輯字庫」，跟住個格式每行一張卡：

apple|蘋果 🍎 例句：I eat an apple. water|水 💧 例句：I drink water. 朋友|朋友係一齊玩嘅人 學校|我哋每日返學嘅地方

英文生字、中文字詞、甚至乘數表（「6×7|42」）都用得 —— 個格式係「題目|答案」，入咩都得。

手機想用？將個 HTML 檔案 WhatsApp 俾自己，手機瀏覽器打開，選單揀「加到主畫面」，小朋友撳個 icon 就玩得，仲唔會亂撳去其他網站。

按需要微調（直接同 AI 講）

  • 「加個語音功能，撳字卡會讀出嚟」（用瀏覽器內置語音合成，英文特別有用）
  • 「答啱十題之後彈個慶祝動畫出嚟」
  • 「加個計時模式，限時 60 秒答最多題」
  • 「字庫分開『中文』『英文』兩組，可以揀邊組溫」

常見問題 FAQ

Q：語音功能讀中文得唔得？

A：得，不過要睇裝置有冇裝中文語音包。iPhone 預設有廣東話/普通話。叫 AI「語音朗讀要支援廣東話」就得。

Q：字庫可以入幾多張卡？

A：幾百張都冇問題，localStorage 好夠装。不過建議按星期分檔，每星期嘅默書範圍一個檔案，溫書先至集中。

Q：星星紀錄會唔會冇咗？

A：只要你唔清除瀏覽器資料，紀錄會一直喺同一部裝置。如果想換機保留，叫 AI 加個「匯出/匯入紀錄」功能。
