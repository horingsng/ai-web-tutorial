「小朋友數學練習網站」

完整逐步教學：從開啟 AI 到生成可用網站，附可直接 Copy 嘅 Prompt 範本，家長必學。

你會整到啲咩？

跟住呢篇教學做，你會整到一個單一 HTML 檔案嘅數學練習網站，功能包括：

  • ➕ 加法 / 減法練習題（數字範圍由你話事，例如 1-20）
  • ⭐ 答啱有星星獎勵動畫，小朋友超有成功感
  • 📊 10 題為一組，做完顯示分數同評語
  • 📱 手機、平板、電腦都用得，離線都用得
  • 💰 成本：$0（用免費 AI 工具）

最正係：整好之後你想改（例如加乘法、改做英文生字），再問一次 AI 就得，唔使重新學。

準備功夫（1分鐘）

你只需要其中一個免費 AI 帳號：

  • ChatGPT（chatgpt.com）— 免費版已經夠用
  • Claude（claude.ai）— 寫 Code 特別好，推薦
  • Kimi（kimi.com）— 中文理解強
三個都係免費註冊。如果係第一次用，我建議用 Claude，佢寫出嚟嘅網站成品率最高。

第一步：複製呢段 Prompt 俾 AI

開啟你揀嘅 AI，成段複製下面嘅指令貼上去，然後按送出：

【角色】你係資深前端工程師，專門設計兒童教育網頁。 【任務】生成一個「小朋友數學練習」網站，單一 HTML 檔案，可直接開啟使用。 【目標用戶】6-8歲香港小朋友（小一至小三） 【功能規格】 - 加法練習，數字範圍 1-20 - 每次出 10 題，一題答完先出下一題 - 每題有 4 個答案選擇（按鈕要大，方便小朋友撳） - 答啱：顯示星星動畫 + 鼓勵語句（例如「好嘢！」「叻仔叻女！」） - 答錯：溫和提示「再試吓」，並顯示正確答案 - 10 題完成後顯示總分（例如 8/10）同評語 - 有「再玩一次」按鈕 【設計要求】 - 風格：鮮豔活潑，使用明亮色彩，適合兒童 - 字體要大（題目至少 36px） - 手機優先設計（響應式） - 用 Emoji 代替圖片，確保離線可用 - 按鈕要有撳落去嘅動畫效果 【技術限制】 - 單一 HTML 檔案，內嵌 CSS + JavaScript - 唔使用外部圖片、框架或網絡資源 - 程式碼要有中文註釋 【輸出】 請輸出完整 HTML code，我會直接儲存為 .html 檔案使用。
呢段 Prompt 嘅威力在於「規格講到好具體」：幾多題、數字範圍、按鈕大細、答啱答錯嘅反應全部寫清楚。AI 越清楚你想要咩，成品就越接近你心中所想。

第二步：將 AI 嘅回覆變成網站（2分鐘）

AI 會輸出一大段由 <!DOCTYPE html> 開頭嘅代碼。跟住做：

1

複製全部代碼

AI 對話框通常有「複製」按鈕，一撳就 Copy 晒。冇嘅話就人手由第一行拖到最後一行全選複製。

2

開個文字編輯器

Windows：開「記事本」（Notepad）。Mac：開「文字編輯」（TextEdit，記得喺「格式」選單揀「製作純文字」）。手機：用任何筆記 App 都得，但電腦做最穩陣。

3

貼上並儲存

貼上代碼，然後「另存新檔」，檔名打 math.html。關鍵位：儲存類型要揀「所有檔案」，編碼揀「UTF-8」，唔好儲存做 .txt。

4

雙擊開啟

雙擊個 math.html 檔案，瀏覽器就會打開你嘅數學練習網站！試玩吓，睇吓啱唔啱用。

第三步：叫 AI 幫你「度身訂造」

初版整好之後，90% 嘅人都想改啲嘢。直接喺同一個對話繼續講就得，例如：

  • 「數字範圍改做 1-100，加埋減法」
  • 「答啱嗰陣加個音效」
  • 「背景改做太空主題，我個仔鍾意火箭」
  • 「加個計時功能，睇吓佢幾耐做完 10 題」

AI 會俾返新版代碼你，重複第二步覆蓋舊檔案就得。改幾多次都得，唔使客气。

如果 AI 輸出到一半停咗（免費版有長度限制），只要打「繼續」佢就會寫落去。記住要完整複製晒所有代碼先好儲存。

第四步（進階）：放上網俾人哋用

想個網站有條公開網址，俾阿嫲喺屋企都用得？可以用 GitHub Pages 免費托管 —— 正正就係你而家睇緊嘅呢個網站用嘅方法。開個免費 GitHub 帳號，開個新 Repository，上傳個 HTML 檔，Settings 開 Pages，就有條 你個名.github.io 嘅網址，詳情我哋遲啲會出專文教。

常見問題 FAQ

Q：儲存咗但打開係一堆文字，唔係網站？

A：九成係儲存嗰陣變咗 math.html.txt。重新「另存新檔」，儲存類型揀「所有檔案（*.*）」，檔名確保係 .html 結尾。

Q：中文變咗亂碼？

A：儲存嗰陣編碼冇揀 UTF-8。重新儲存一次，編碼揀 UTF-8 就搞掂。

Q：可以整英文生字卡、乘數表嗎？

A：絕對可以！將 Prompt 入面「加法練習，數字範圍 1-20」改做你想要嘅內容就得，例如「英文生字配對遊戲，用小三程度生字」。

Q：用邊個 AI 最好？

A：寫網站 Code，Claude 同 ChatGPT 都好穩定。你可以將同一段 Prompt 貼俾唔同 AI，比較吓邊個成品最啱你心水 —— 呢個都係樂趣之一。

總結

你今日學識咗嘅嘢，其實係一個可以無限重用嘅技能：「講清楚你想要咩 → AI 寫 → 儲存做 .html → 開啟使用」。數學練習只係開始 —— 生字卡、時間表、獎勵表，全部都用同一招整到。
