「報價單生成器」

輸入產品同價格，一鍵生成專業報價單。自動計算總額、直接列印或儲存 PDF 俾客。

點解要自己整？Excel 唔得咩？

得，但 Excel 報價單有幾個痛位：要開電腦先填到、格式成日走位、計數要自己 set formula、發俾客人唔夠體面。自己用 AI 整一個網頁版報價單生成器：

  • 📱 手機都填到 —— 喺客面前即場開單，幾有型
  • 🧮 自動計數 —— 數量 × 單價、折扣、總額全部自動
  • 🖨️ 一鍵列印 / 存 PDF —— 直接發俾客，夠專業
  • 💾 記住公司資料 —— 公司名、地址、電話填一次，以後自動帶入
  • 🆓 免費 —— 唔使訂閱任何軟件

第一步：複製 Prompt 俾 AI

【角色】你係資深前端工程師，專門設計商業工具網頁。 【任務】生成一個「報價單生成器」網站，單一 HTML 檔案，可直接開啟使用。 【目標用戶】香港小店主、Freelancer、網店店主 【功能規格】 - 公司資料區：公司名、電話、電郵、地址（用 localStorage 記住，下次自動填入） - 客戶資料區：客戶名稱、聯絡人、日期（預設今日）、報價單編號（自動遞增） - 產品明細表：每行有「項目描述、數量、單價、小計」，可自由加行刪行 - 自動計算：每行小計、全部小計、折扣（百分比）、最終總額，輸入即時更新 - 貨幣顯示：港幣 HK$，千位分隔（例如 $12,500.00） - 底部有條款欄（可自訂，例如「報價有效期30日」） - 「生成報價單」按鈕：切換到打印預覽模式，淨係顯示報價單內容，冇輸入框 - 「列印 / 儲存PDF」按鈕：呼叫 window.print()，CSS 有 @media print 優化排版 【設計要求】 - 簡約專業風格，白底黑字，商務感 - 打印預覽要似正式文件：有公司名置頂、表格線、總額粗體 - 手機同電腦都用到（響應式） 【技術限制】 - 單一 HTML 檔案，內嵌 CSS + JavaScript - 唔使用外部圖片或框架 - 支援離線使用 - 程式碼要有中文註釋 【輸出】 請輸出完整 HTML code，我會直接儲存為 .html 檔案使用。

第二步：儲存並測試

1

複製完整代碼，儲存做 quote.html

記事本貼上 → 另存新檔 → 檔名 quote.html → 類型「所有檔案」→ 編碼 UTF-8。

2

開啟，填你嘅公司資料

填一次，以後開返個檔案佢會自動記住（localStorage）。

3

試開一張單

入兩三行產品，睇吓小計同總額啱唔啱數，跟住撳「生成報價單」→「列印」→ 揀「另存為 PDF」，一份專業報價單就誕生。

第三步：常見自訂要求

  • 「加個上傳公司 Logo 嘅功能」
  • 「加稅項欄（例如 5% GST）」
  • 「報價單編號格式改做 Q-2026-001 咁」
  • 「加英文版切換掣，我有啲客係外國人」
  • 「加個『轉做發票 Invoice』模式」
列印 PDF 嗰陣，如果發現排版唔靚，同 AI 講「打印版式有問題，幫我優化 @media print 嘅 CSS」，通常一次搞掂。

做生意仲可以整咩？

識咗呢一招，一大串商業工具都整到：

  • 📦 訂單記錄表 —— 邊個客、買咗咩、送咗貨未
  • 📅 預約登記表 —— 美容院、補習社、維修檔期
  • 🏷️ 價目表產生器 —— 整張靚價目表 Cap 圖發 IG
  • 📊 每日營業額記錄 —— 一個月落嚟有圖表睇

常見問題 FAQ

Q：資料會唔會上傳去邊？安唔安全？

A：完全唔會。呢個係純前端網頁，所有資料只存喺你部機嘅瀏覽器（localStorage），冇伺服器、冇上傳，離線都用得。

Q：換咗部電腦，公司資料冇咗？

A：係，localStorage 跟裝置走。將個 HTML 檔案放喺雲端（Google Drive），每部機都開同一個檔，重新填一次公司資料就得。

Q：可以儲存返舊報價單紀錄嗎？

A：可以，同 AI 講「加個歷史紀錄功能，儲存晒所有出過嘅報價單，可以搜尋同重新載入」。
