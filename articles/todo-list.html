「To-do List 待辦清單」

開 App 要睇廣告先加到一項 task？自己整嘅極簡版：打開就入，入完就走。

點解 To-do App 越嚟越難用？

你淨係想記低「聽日交租」呢五個字，但而家嘅待辦 App 要你：開帳號 → 揀計劃 → 彈個訂閱優惠 → 開「工作區」→ 揀「專案」→ 先加到一項。研究顯示人嘅短期記憶得幾秒 —— 搞完呢輪，你已經唔記得自己要記咩。

To-do list 嘅本質係快。自己整一個：打開、打字、撳加入、閂 —— 三秒搞掂。冇帳號、冇廣告、冇訂閱，仲可以跟足你嘅習慣改。

成品功能預覽

  • ⚡ 頂部輸入框打字撳加入，三秒一項
  • 🏷️ 優先級：高（紅）/ 中（黃）/ 低（灰），自動排次序
  • 📅 到期日（選填），過期自動標紅提醒
  • ✅ 撳一下就剔走，剔走嘅自動沉底加刪除線
  • 📊 頂部顯示今日進度：「5 項完成 3 項」

第一步：複製 Prompt 俾 AI

開啟 ChatGPT、Claude 或 Kimi，成段複製貼上：

【角色】你係資深前端工程師，擅長設計極簡高效嘅生產力工具。 【任務】生成一個「To-do List 待辦清單」網站，單一 HTML 檔案，可直接開啟使用。 【目標用戶】想要一個極簡、快速、冇廣告嘅待辦清單嘅香港人 【功能規格】 - 頂部一個大輸入框 + 「加入」按鈕，撳 Enter 都加到 - 每項待辦顯示：剔選框、內容、優先級顏色點、到期日（如有）、刪除掣 - 加入時可以揀優先級：高（紅）/ 中（黃）/ 低（灰），預設中 - 加入時可以揀到期日（日期選擇器，選填） - 排序邏輯：未完成排前面，按優先級高至低排；已完成沉底，加刪除線同變灰 - 剔選框撳一下切換完成/未完成 - 到期日已過但未完成嘅項目，日期顯示紅色 + 「已過期」標籤 - 今日到期嘅項目，日期顯示橙色 + 「今日到期」標籤 - 頂部顯示進度統計：「共 X 項 · 完成 Y 項 · 今日到期 Z 項」 - 「清除已完成」按鈕 - 所有資料用 localStorage 儲存 【設計要求】 - 極簡風格，白底，大量留白，重點係「快」 - 手機優先設計（響應式） - 每項待辦係一張圓角卡片，好撳易睇 - 加入新項目時有輕微動畫 【技術限制】 - 單一 HTML 檔案，內嵌 CSS + JavaScript - 唔使用外部圖片或框架 - 完全離線可用 - 程式碼要有中文註釋 【輸出】 請輸出完整 HTML code，我會直接儲存為 .html 檔案使用。

第二步：儲存做 HTML 檔案

1

複製 AI 輸出嘅完整代碼

由 <!DOCTYPE html> 到最後 </html>，一行都唔好漏。

2

記事本貼上，另存新檔

檔名 todo.html，儲存類型揀「所有檔案」，編碼 UTF-8。

3

雙擊開啟，即刻入幾項試吓

入「聽日交租」揀高優先、揀聽日做到期日，應該見到紅點同「今日到期」式標籤（如果到期日係今日）。剔走佢，睇吓佢沉唔沉底。

第三步：放上手機主畫面

將個檔案傳上手機，瀏覽器開啟 → 「加到主畫面」。以後諗到要做咩，撳 icon、打字、撳加入 —— 三秒搞掂，快過喺 WhatsApp 群組 send 俾自己。

想分「工作」「私人」兩類？同 AI 講「加個分類功能，每項可以揀類別，頂部可以篩選」—— 你嘅工具，你想點就點。

按需要微調（直接同 AI 講）

  • 「加個編輯功能，撳項目中間可以改內容」
  • 「加個搜尋框，即打即篩」
  • 「每日第一次打開時，彈出今日到期嘅項目提醒」
  • 「加個匯出功能，將清單變成文字方便分享」

常見問題 FAQ

Q：換咗電話啲資料會唔會跟？

A：唔會，localStorage 係每部裝置獨立嘅。想跨裝置同步就要加後端資料庫，屬於進階玩法 —— 大部分人其實手機一份清單就夠。

Q：同手機內建備忘錄有咩分別？

A：備忘錄係「記嘢」，呢個係「管嘢」—— 有優先級、有到期提醒、有進度統計、剔走自動沉底。仲有就係：呢個係你自己整嘅，想加咩功能一句說話就得。

Q：可唔可以整俾成個團隊用？

A：單機版唔得，但你可以跟 放上网教學 將佢放上网，團隊各自用自己嗰份。想真正多人協作，就要學埋接資料庫 —— 嗰個係下一階段嘅教學。

總結

生產力工具嘅最高境界係「感覺唔到佢存在」—— 諗到就記低，記低就繼續做嘢。自己整嘅 To-do list 就係咁：冇帳號、冇廣告、冇學習成本。到呢篇為止，你手上應該已經有十幾個自己整嘅工具，唔該晒 App Store 👋。想睇多啲？去 文章庫 慢慢揀。
