「個人化揀股篩選器」

呢篇係技術教學，教你點樣用 AI 整工具整理自己嘅研究資料，並唔構成任何投資建議。投資涉及風險，過往表現唔代表將來，做決定前請諮詢持牌專業人士。

點解要「個人化」篩選器？

網上大把「十大必買股」名單，但每個人嘅情況都唔同：

  • 🎯 有人要收息（退休人士）— 最緊要股息率穩定
  • 🚀 有人要增長（後生仔）— 睇收入增長同行業前景
  • 🛡️ 有人要穩陣 — 睇負債比率、盈利穩定性
  • 💰 有人預算有限 — 入場費太貴嘅股直接略過

現成嘅免費 Screener（例如 Yahoo Finance 嗰個）功能又硬又唔貼身。自己整一個：準則你話事、權重你話事、仲可以加自己嘅研究筆記。佢唔會話你知買邊隻，但會幫你用自己嘅尺，度出一個屬於你嘅觀察名單。

工具點運作？（講清楚先好整）

呢個工具係一個「評分表」：你自己輸入研究返嚟嘅數據（由年報、財經網站睇返嚟），工具幫你：

  • 📋 儲存每隻股票嘅關鍵數據（市盈率、股息率、負債比率、行業…）
  • ⚖️ 按你設定嘅權重自動評分（例如收息型：股息率佔 40 分）
  • 📊 自動排名，一眼睇到邊隻最啱你嘅準則
  • 📝 每股加研究筆記（「管理層誠信有疑問」「等佢跌穿 $50 先諗」）

第一步：複製 Prompt 俾 AI

【角色】你係資深前端工程師，專門設計投資研究工具網頁。 【任務】生成一個「個人化股票觀察名單評分器」，單一 HTML 檔案，可直接開啟使用。 【目標用戶】香港散戶投資者，想按自己準則整理股票研究 【功能規格】 - 新增股票：股票代號、名稱、市場（港股/美股）、行業、現價、入場費（每手金額） - 數據欄位：市盈率 PE、股息率%、收入增長率%、負債比率%、自由評分（1-10，對間公司嘅主觀信心） - 權重設定區：五個準則（PE、股息率、增長、負債、主觀信心）各自嘅重要程度（0-100%），用 slider 調較 - 自動評分：按權重計算每隻股票嘅總分（0-100），邏輯：PE 越細越高分、股息率越高越高分、增長越高越高分、負債越細越高分、主觀信心直接用 - 名單自動按總分排序，前三名有金銀銅牌標示 - 每隻股票可以摺疊展開，入面有筆記欄（多行文字） - 可以刪除股票 - 全部資料用 localStorage 儲存 【設計要求】 - 深色專業風格，似財經終端機 - 總分用大數字 + 顏色（80+綠色、60-79黃色、60以下灰色） - 手機同電腦都用到（響應式） 【技術限制】 - 單一 HTML 檔案，內嵌 CSS + JavaScript - 唔使用外部圖片或框架 - 離線可用，冇任何網絡請求 - 程式碼要有中文註釋 - 頁面底部加免責聲明：「本工具僅供整理個人研究，不構成投資建議」 【輸出】 請輸出完整 HTML code，我會直接儲存為 .html 檔案使用。

第二步：儲存並建立你嘅名單

1

儲存做 stocks.html

老規矩：複製完整代碼 → 記事本 → 另存新檔 → 「所有檔案」→ UTF-8。

2

設定你嘅權重（最緊要嘅一步）

問自己：我最重視咩？收息型可以試：股息率 40%、負債 25%、主觀信心 20%、PE 15%、增長 0%。增長型就將增長同收入權重調高。冇標準答案，呢個就係「個人化」嘅意思。

3

輸入你研究過嘅股票

喺財經網站（AASTOCKS、Yahoo Finance）搵到嘅數據逐隻入落去。入完五六隻，個排名就開始有參考價值。

4

寫筆記，定期更新

每隻股寫低「點解留意佢」「咩價位先考慮」「有咩風險」。一個月後更新數據，排名會郁 —— 呢個過程本身已經令你成為更自律嘅投資者。

點樣用得聰明？

  • 🔍 佢係「篩選」唔係「聖杯」：工具幫你排序研究優先次序，但最後決定一定要落返基本面研究
  • 📅 定期覆核：出完業績就更新數據，排名郁咗要問自己點解
  • 🧘 主觀信心欄好有用：逼你將「感覺」量化，你會發現自己對邊啲公司真係了解、邊啲只係道聽途說

常見自訂要求

  • 「加個欄位記錄我嘅目標價同止蝕價」
  • 「加『已持有』分頁，分開觀察名單同持倉」
  • 「加匯出 CSV，我想喺 Excel 再分析」
  • 「評分邏輯加入 PEG（市盈率相對增長比率）」

常見問題 FAQ

Q：點解唔直接連線攞即時股價？

A：即時數據要 API 同伺服器，複雜好多（我哋遲啲出進階篇教）。而家手動入數據其實有個好處：逼你真係研究過先入，唔會亂咁加股票。

Q：個評分準唔準？

A：佢準確執行你設定嘅邏輯，但垃圾入垃圾出 —— 如果你嘅權重唔合理或者數據入錯，結果都會誤導。當佢係幫你整理思路嘅工具，唔係預言機。

Q：美股港股嘅數據喺邊度搵？

A：Yahoo Finance、AASTOCKS、富途、公司年報都有。建議用公司官方年報嘅數字最穩陣。

總結

投資最危險嘅唔係冇工具，係用緊人哋嘅尺嚟度自己嘅決定。你今日整嘅唔只係一個網頁，係一套屬於你自己嘅投資紀律。由乱咁聽消息，變成有系統咁研究 —— 呢個先係散戶最值錢嘅升級。
