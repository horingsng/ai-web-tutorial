點解唔直接用記帳 App？

記帳 App 好多，但你有冇試過：

  • 😤 用兩用就彈廣告，唔畀錢開會員仲唔准用圖表？
  • 😟 啲使費資料上晒人哋伺服器，唔知俾邊個睇？
  • 🤷 分類永遠唔啱自己 —— 我想要「飲茶」分類佢淨係得「餐飲」？

自己用 AI 整一個，呢啲問題一次過解決：分類你話事、冇廣告、資料 100% 喺你部機，仲可以隨時加功能（例如「每月固定開支提醒」）。

第一步：複製 Prompt 俾 AI

【角色】你係資深前端工程師，專門設計個人理財工具網頁。 【任務】生成一個「家庭記帳工具」網站，單一 HTML 檔案，可直接開啟使用。 【目標用戶】香港家庭用戶、想控制使費嘅上班族 【功能規格】 - 快速記錄：金額、類型（收入/支出）、分類、日期（預設今日）、備註 - 支出分類：飲食、交通、屋企、娛樂、購物、醫療、其他（每類配一個 Emoji） - 收入分類：薪金、兼職、投資、其他 - 記錄列表：最近記錄排最前，顯示 Emoji、分類、金額（支出紅色、收入綠色）、日期，可以刪除 - 本月總覽：本月總收入、總支出、結餘，大字顯示 - 分類統計：用純 CSS 畫橫條圖，顯示本月各支出分類金額同佔比 - 月份切換：可以睇返之前月份嘅記錄 - 全部資料用 localStorage 儲存 【設計要求】 - 簡約風格，白底，大量留白，易讀 - 金額用港幣 HK$，千位分隔 - 手機優先設計（記帳多數喺手機做） - 記錄按鈕要大好撳 【技術限制】 - 單一 HTML 檔案，內嵌 CSS + JavaScript - 唔使用外部圖片、圖表庫或框架 - 完全離線可用 - 程式碼要有中文註釋 【輸出】 請輸出完整 HTML code，我會直接儲存為 .html 檔案使用。

第二步：儲存並開始用

1

儲存做 budget.html

複製 AI 完整代碼 → 記事本貼上 → 另存新檔 → 類型「所有檔案」→ 編碼 UTF-8。

2

傳去手機，加到主畫面

記帳係隨身嘢：將檔案傳去手機，瀏覽器打開 → 選單「加到主畫面」→ 以後一撳 icon 就記到數。

3

建立記帳習慣

每日沖涼前用 1 分鐘記返當日使費。記得一個月，你會第一次真正睇清楚自己啲錢去咗邊。

第三步：整到啱自己心水

  • 「加個『飲茶』分類，我每個禮拜都去」
  • 「加每月預算功能，超支嗰陣彈警告」
  • 「加個圓餅圖睇分類佔比」
  • 「加匯出 CSV 功能，年尾攞去 Excel 做全年總結」
  • 「加固定開支：每月 1 號自動記管理費 $2,000」
「匯出 CSV」係必加功能 —— 資料喺自己手，想點分析都得，仲唔怕以後換工具啲 data 冇咗。

進階玩法：全家一齊記

同屋企人一齊記帳效果加倍，不過 localStorage 跟裝置走，有兩個玩法：

  • 簡單版：每人自己記自己嗰份，月尾夾數
  • 進階版：將個工具升級做有伺服器嘅版本（呢個涉及後端，我哋遲啲出專文教）

常見問題 FAQ

Q：換手機啲記錄會唔會冇咗？

A：會，localStorage 跟裝置。所以記住加「匯出 CSV」功能，每月匯出一次做備份，換機都唔怕。

Q：資料真係唔會上網？

A：真係。呢個檔案冇任何網絡請求，你大可以開咗飛行模式嚟用 —— 離線用到就係最好嘅證明。

Q：可以同銀行戶口同步嗎？

A：唔可以，呢類純前端工具讀唔到銀行資料（都唔應該俾佢讀）。手動記帳雖然麻煩少少，但「親手記低」本身就係令你慳錢嘅心理機制。

總結

理財第一步唔係投資，係知自己啲錢去咗邊。一個完全屬於你、冇廣告、冇訂閱費嘅記帳工具，今日已經喺你手。記得一個月之後，你就會明點解咁多人話記帳改變人生。
